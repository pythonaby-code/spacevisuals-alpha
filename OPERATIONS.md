# Управление SpaceVisuals Alpha

## Текущее состояние

Сайт работает локально: http://localhost:4187. Исходный SpaceVisualsAlphaSite не изменяется. Платежи отключены. Акция по умолчанию выключена; победитель ещё не определён. Проверки проходят на отдельных данных и тестовых ключах.

## Общий вход на этом ПК

Сайт читает аккаунты из `%LOCALAPPDATA%/SpaceClient/accounts.json`. Пароль проверяется тем же scrypt, что в лаунчере; допустимы 8–128 символов. Входящий существующий аккаунт получает запись сайта после проверки пароля. Новый аккаунт сайта добавляется в общее хранилище лаунчера с резервной копией, прежние записи сохраняются. Ник новой регистрации: 3–16 латинских букв, цифр или `_`.

Если в сайте и лаунчере разные аккаунты с одинаковым ником и разными паролями, автоматическое объединение запрещено: требуется отдельная привязка, данные не заменяются.

Это **локальное объединение**, не облачный аккаунт. На другом компьютере локальные аккаунты лаунчера сами не появятся на сайте. Для публичного запуска необходимы центральная авторизация и обновление лаунчера под неё; текущий сервер принимает только localhost.

## Приглашения друзей

Запусти `open-owner-menu.cmd` и выбери создание приглашения. Ссылка одноразовая и действует 30 дней. Друг должен войти/зарегистрироваться именно по ней **до скачивания**. Если уже вошёл, он явно применяет приглашение к показанному аккаунту. Такой аккаунт исключается из автоматического подарка. Само приглашение не выдаёт Pro.

Для ручной выдачи выбери пункт 2, введи ник и срок в днях. Аккаунт должен уже существовать на сайте. Команда отмечает друга и создаёт подписанную лицензию; её можно скачать в профиле. Повторная выдача продлевает текущий срок.

Пока сайт на localhost, ссылки доступны только на этом ПК. После публикации ссылки должны строиться с реальным адресом через `SITE_PUBLIC_URL`; нынешние localhost-ссылки нельзя использовать как публичные.

## Подарок первому скачавшему

В меню владельца есть включение и приостановка акции. Включать при готовности к запуску, после подготовки приглашений. Срок подарка — 30 дней. Побеждает первый вошедший в аккаунт участник без отметки друга, которому сервер полностью передал архив обычным GET-запросом с ответом 200.

HEAD, частичные Range-запросы, прерванные передачи и анонимные скачивания подарка не выдают. Друзья пропускаются. Уникальный победитель записывается в транзакции с выдачей лицензии; повторные скачивания и перезапуск сервера не создают второго подарка. Сервер подтверждает передачу архива, а не факт его сохранения/распаковки на ПК пользователя. Для возобновляемых скачиваний Range участие пока не учитывается.

Ручные выдачи не занимают подарок. Сброс победителя через меню отсутствует.

## Активация Pro

Подписка отображается в профиле с датой окончания и анимацией фактической выдачи. Скачай файл лицензии, затем в лаунчере открой «Профиль → Активировать Pro» и выбери файл. Автоматическая установка лицензии в клиент не выполняется. Проверен формат лицензии настоящим проверяющим кодом лаунчера; запуск игрового клиента для этой доработки не выполнялся.

Закрытый ключ читается только сервером из существующего ProService/data; в сайт и архив клиента он не копируется. В проверках используются отдельные тестовые ключи.

## Запуск и проверки

Node.js 24+:

```powershell
node server.mjs
node test-membership.mjs
```

Рабочая база `.data/site.sqlite` и общее хранилище аккаунтов не участвуют в тестах. Обновление не копирует прежнюю базу сайта. Серверные тесты проверяют вход лаунчера, регистрацию в обе стороны, сохранность данных, приглашения, ручную выдачу, одного победителя при конкурентных скачиваниях, подпись лицензии, перезапуск, истечение и запрет реальной оплаты. Браузером проверены вход с 10-символьным паролем, приглашение, отметка друга, получение Pro и интерфейс на 1440/390 px.

Дальнейшая реальная оплата требует выбора доступного владельцу способа приёма платежей и публичного HTTPS-сервера. Пока ни деньги, ни тестовый статус заказа не дают платную Pro.
