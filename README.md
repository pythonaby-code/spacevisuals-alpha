# SpaceVisuals Alpha

Фиолетово-белый сайт SpaceVisuals: реальные кадры клиента, адаптация для телефона, живой градиент заголовков и локальный личный кабинет.

## Запуск

Нужен Node.js 24+. Сторонних npm-зависимостей нет.

```sh
npm start
```

Открой http://localhost:4187. Архив клиента можно скачать из Releases и положить в `dist/downloads/SpaceClient-Alpha-Windows.zip` для локального скачивания. Контрольная сумма — в `dist/downloads/checksums.json`.

## Что работает локально

- На Windows — общий вход с локальным SpaceClient, пароли 8–128 символов. Новые аккаунты добавляются с резервной копией прежнего хранилища.
- Одноразовые приглашения друзей, исключение этих аккаунтов из акции и ручная выдача подписки.
- Один подарок за первое полное авторизованное скачивание: 30 дней Pro. По умолчанию акция выключена.
- Подписанные лицензии и анимация фактического получения Pro. Для выдачи нужны ключи существующего издателя вне репозитория.

На другом ПК его локальные аккаунты не становятся облачными автоматически. Центральная авторизация и обновление лаунчера под неё пока не реализованы. Эта версия сервера слушает только localhost. Реальная оплата отключена, платёжного кабинета нет.

Подробности и управление — [OPERATIONS.md](OPERATIONS.md). Рабочие базы, пароли, приглашения и ключи в репозиторий не входят.

## GitHub Pages

`docs/` — отдельная статическая витрина. В ней работают галерея и градиент, скачивание направляется в GitHub Releases после сборки с адресом репозитория. В профиле показано честное сообщение о подготовке публичного сервера; пароль в статическую страницу не вводится. Подарок за скачивание через Pages не разыгрывается.

```sh
npm run build:pages -- --repository=OWNER/REPOSITORY
npm run check:publish
```

В настройках Pages выбери `main`, папку `/docs`. Архив клиента больше ограничения Git для одного файла, поэтому его нужно приложить к выпуску с тегом `alpha-client`, не коммитить.

## Проверки

```sh
npm test
```

Тесты используют временные аккаунты, архив и отдельную пару ключей. Проверяются совместимость лаунчера, сохранность данных, приглашения, ручная выдача, конкурентные скачивания с одним победителем, подпись лицензии, повторные запросы, перезапуск и отключённая оплата.

Manrope распространяется по SIL Open Font License; лицензия в `dist/assets/OFL-Manrope.txt`. Пользовательские логотип и изображения клиента сохранены.
